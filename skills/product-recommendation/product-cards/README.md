# 产品卡最小结构（Product Card）

每个可推荐产品版本必须具备以下字段。产品卡是对权威材料的结构化投影，必须能追溯回源文件与条款。缺少有效版本、Owner 或来源的产品不得进入生产推荐全集。

## 必填字段

- 产品 ID、名称、产品族、版本、状态、生效/失效时间；
- 适用客户与适用场景；
- 产品能力和解决的问题；
- 客户价值（不使用无依据营销用语）；
- 准入条件、排除条件和禁止用途；
- 前置产品、互斥产品、替代产品和配套产品；
- 流程、材料、协同角色和办理时效口径；
- 价格/利率/费率的可表达边界；
- 风险提示、禁止承诺事项和人工复核要求；
- 制度条款、产品文档、案例和来源定位（EvidenceRef）；
- Owner、审核人、发布时间和内容哈希。

## 不可变版本语义

- `ProductVersion` 发布后不可变，只可退役（`hasVersion`，INV-01）；
- `ProductVersion` 提供 `offersCapability`（能力绑定版本）；
- `ProductVersion` 受 `RuleBundle` 治理（规则包独立版本与 Owner）；
- 产品卡非最终权威本身；必须追溯回源文件与条款。

## 试点产品族

首期选择一个高频、资料较完整、规则可表达的产品族（如流动资金融资或跨境结算），不一次性覆盖全部产品。试点产品族清单与权威材料由公司金融产品 Owner 裁决（OQ-02）。
