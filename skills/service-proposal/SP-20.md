# SP-20 对公客户服务建议书生成

基于 ContextPackage（企业数据 + 公开数据 + 交互历史/记忆）逐章生成 8 章建议书，
输出结构化 claims（F/C/B/H/P/A 事实标签）+ citations + unknowns + 确定性双版本过滤 + 闸门建议。
规则：所有断言必须有引用；内部版保留风险红旗；对客版仅 F/A；闸门顺序不可跳；标签必填。
