# 财务分析框架（复用资产）

## 比率口径
- 毛利率 = (营收-营业成本)/营收；净利率 = 净利润/营收
- 流动比率 = 流动资产/流动负债；资产负债率 = 总负债/总资产
- 经营现金流/净利润比：>1 为佳

## 分析维度
1. 盈利能力（3 年趋势）2. 偿债能力（短/长期）3. 现金流质量 4. 营运能力 5. 异常信号（应收/存货激增、现金流与利润背离）

## 输出纪律
- 数值断言标 F（来源=财务摘要）；由比率引申的结论标 C；趋势外推标 H。
