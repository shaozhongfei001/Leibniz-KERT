## 2. 为何采用"双源"（**必须写清，防误读**）

- **权威源**（外汇局官网）本次**只载发布通知**，条文在**附件 `.doc`** 内 —— 直取返回**二进制、无法解析**（已实测）。
- **承载源**（政府网站 HTML 转载）**可解析**，提供 5 章 33 条条文，但**页面本身不含**发布机关、文号、
  发布日期、实施日期（也未含附件与废止目录）。
⇒ **处置**：条文取自承载源；文号与日期取自权威源通知；二者**分别记入 front matter 与本节**，
**不把转载页当作权威发布**，也不以通知冒充条文。

## 3. 失败与绕行记录（如实登记）

- 第一手：直接抓 `safe.gov.cn` 附件 `.doc` ⇒ 返回**二进制乱码**，**不可用**（未入库）。
- 第二手：检索到政府网站 HTML 转载承载 ⇒ 取得逐字条文后入库。
- ⚠ 承载页提示："**该规定后续有相关配套文件与调整**" ⇒ 见 §4 未完成项。

## 4. ⚠ 凭据强度的如实声明（不掩盖）

- 入库件是**依据政府网站转载页面所载文本的转写**，**不是**原始 HTML 字节快照
  ⇒ `bytes_sha256` 只保证**入库文件自身**的字节完整性，**不主张**与任何站点字节一致。
- `clause_verified=false`：条款号未经 Owner 核定，不得作确定性依据。
- **未完成**：① 未取得外汇局官方 `.doc` 附件原文逐字核对（字形/标点/分项编号）；
  ② **未确认本规定是否已被后续文件修订或调整**（承载页明确提示存在"相关配套文件与调整"）——
  该项**必须在产品解读对客使用前由合规确认**。
- **未做**：本行合规对"现行有效性 / 适用性"的确认。
