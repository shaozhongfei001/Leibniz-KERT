# 01_raw：源文件引用层

> 状态块：
> - **CANDIDATE**
> - **FROZEN=NO**
> - **IMPLEMENTED=NO**

## 语义

`01_raw` 是 DKWS 五层工作区的**源文件引用层**：登记权威制度/监管材料的来源标识、标题与条款定位，供 `03_core` 产品卡的 EvidenceRef 引用。**本层不存放产品卡权威内容**，权威产品卡唯一落在 `03_core`。

## 本包内容

- `source-registry.md`：7 条权威源文件登记（5 条行内制度 + 2 条监管法规），含条款定位。
- 权威材料正文**当前未提供**（对应 Gate 0 §7.3 OQ-02「试点产品族清单与权威材料由公司金融产品 Owner 裁决」），本层仅登记引用、条款号标「待 Owner 核定」，**不臆造材料内容**。

## 与产品卡的可追溯性

每张产品卡 `## EvidenceRef` 的 `source_id` 均回指本层 `source-registry.md` 登记条目；待权威材料上传后，将按源文件真实章节/条款号回填 `clause` 字段，并重算产品卡内容哈希。
